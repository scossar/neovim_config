# Neovim configuration

This config uses [LazyVim](https://www.lazyvim.org/). The local Omarchy
`Flexoki Light` theme selects the [`scossar/flexoki-paper`](https://github.com/scossar/flexoki-paper)
colorscheme. Its development checkout currently lives in `lua/flexoki-paper/`;
that directory is a standalone Neovim plugin repository and can be moved to
`~/projects` after it is pushed to GitHub.
